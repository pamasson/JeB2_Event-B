# JeB2: Rodin Plugin and Ressources

This repository gives public access to an extension of the Rodin plug-in for dealing with scenarios. It also contains other ressources: 

- Event-B models for the MLV case study
- JeB's generated simulators from MLV: ready to use, customized with graphical display, constants valuation and event parameters generators
- JSON files with MLV scenarios validated

# JeB plugin (in `JeB2Plugin`)

The JeB plugin is in the file `fr.loria.dedale.bsimu-0.6.6-SNAPSHOT.jar`. To install it, simply drop it into the `dropins` directory of Rodin and relaunch it. An icon `JeB` should appear in the toolbar. Clicking on it will open a dialog asking you for which Rodin projects you want to generate JeB animation files. The simulators will be generated inside directories called `jeb` in each project.


## Event-B models for the MLV Case Study (in `EventBModels`)
These models are for the [ABZ'24 MLV case study](https://github.com/foselab/abz2024_casestudy_MLV).

They were written by Amel Mammar and published at the ABZ'24 conference. The full models are made available by Amel Mammar as a [PDF File on GitHub](https://github.com/AmelMammar/MechanicalLungVentilator/blob/main/EventBModels.pdf)

We give here the first two refinement levels and their contexts in text format.  They can easily be imported in Rodin thanks for exampe to a text editor such as Camille.

Context and Model for the GUI (first refinement):

- `1_CTX_GuiStates.txt`
- `2_MCH_GuiSM.txt`

Context and Model for the Controller (second refinement):

- `3_CTX_ContStates.txt`
- `4_MCH_ContSM.txt`

## Ready-to-use MLV simulators Generated by JeB and customised (in `MLV_JeBAnimators`)

The JeB animation files generated by *our extension of JeB* for the MLV Models are to be found in the `jeb.zip` archive. 
Unzip it. the simulators are ready to use. A customized graphical display is available for the GUI model. The graphic customization is located in the file `jeb/public/2_MCH_GuiSM_user.js`.

To launch a JeB animation, navigate to the `jeb` folder where you find such files as `config.json`, `init-server.sh`, `start-server.sh`, etc. To have the simulator communicating with the ProbCLI constraint solver, you can set the path to your ProBCLI installation in the `config.json` file. To init and start the server successively run:

- `./init-server.sh` (or `init-server.bat` if you're on the Windows platform)
- `./start-server.sh` (or `start-server.bat` if you're on the Windows platform)

The last command should answer with a message saying that `Server is running at http://localhost:3000`.

Open the location `http://localhost:3000` in your browser: you are presented with an HTML interface where you can click on any of the refinement level.

## MLV Scenarios Validated (in `Scenarios`)

The [MLV GitHub page](https://github.com/foselab/abz2024_casestudy_MLV) for the MLV Case Study provides in a PDF document a [set of scenarios to be validated](
https://github.com/foselab/abz2024_casestudy_MLV/blob/main/scenarios_v_1_5.pdf). 

We have animated these scenarios on our JeB simulators and exported them as the following JSON files. They can be replayed by importing them with the `import` button just above the Scenario frame in the simulator. As we have two levels of refinement, the scenarios are split between their GUI part and their controller part.  

### Scenarios to replay on the GUI simulator

- `scenarGUI_1.json` (new patient)
- `scenarGUI_2.json` (resume ventilation)
- `scenarGUI_3.json` (error in the self test)
- `scenarGUI_4.json` (test interrupted)


### Scenarios to replay on the Controller simulator

- `scenarCONT_1.json` (new patient)
- `scenarCONT_2.json` (resume ventilation)
- `scenarCONT_3.json` (error in the self test)
- `scenarCONT_4.json` (test interrupted)

Additionally, a scenario generated by the ProB model-checker that can be replayed on the GUI simulator is found in file `scenarProB_MC.json`.
